# 🩸 LifeLink - Blood Donation Management System

Creative Blood Donor Finder - Find donors instantly in INDIA-GOA!

## ✨ Features
- 🎨 Creative Donor Cards with Blood Badges
- 🔍 Instant Search by Blood Group
- 👥 Role Based Login - Admin (CRUD) & User (View + Add)
- 📞 Validation: Phone = Exactly 10 digits, Email = @gmail.com only
- 🌐 Public View - No login needed to see donors

## 🛠️ Tech Stack
PHP, MySQL, HTML, CSS, XAMPP

## 🔑 Login Details (For Testing - Localhost Only)

**User Access:**

- Features: View + Add Donors

## 🚀 How to Run
1. Copy folder to `C:\xampp\htdocs\`
2. Start Apache & MySQL in XAMPP
3. Import `blood_donation.sql` in phpMyAdmin
4. Open `http://localhost/blooddonation/`
5. Login with above credentials
